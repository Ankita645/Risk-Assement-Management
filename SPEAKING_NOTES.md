# Second-review speaking notes — updated Groq/LangChain implementation

## Project overview
“My project is an AI-Based Software Release Risk Prediction and Decision Support System. Instead of training a traditional machine-learning classifier in this prototype, I use a Groq-hosted large language model through LangChain to assess the release details and defect description. The system classifies risk as High, Medium, or Low and explains the decision.”

## Workflow
1. “The user enters changed files, changed lines, affected modules, unresolved defects, release criticality, and recent release failures.”
2. “The user also enters a natural-language description of the defect or known issue.”
3. “The browser sends the inputs to the FastAPI backend.”
4. “The backend uses LangChain's ChatGroq integration to send the inputs with a carefully designed system prompt to the configured Groq model.”
5. “The model returns a risk level, rationale, and recommended actions. The backend validates the structure and generates an Excel report with the input values and result.”
6. “The user reviews the result and downloads the Excel report. This is decision support, not automatic release approval.”

## Tools
- Frontend: HTML, CSS, JavaScript
- Backend/API: Python, FastAPI, Uvicorn
- LLM integration: LangChain Core and `langchain-groq` / `ChatGroq`
- Secret/configuration management: `python-dotenv` and `.env`
- Excel output: `openpyxl`
- External model service: Groq API

## Important limitation to state clearly
“The risk classification is generated by an LLM and is not statistically validated against a labelled historical release dataset in this version. Model output may be imperfect, so a release owner must review the rationale and recommendations. The prototype does not deploy software or approve releases automatically.”
